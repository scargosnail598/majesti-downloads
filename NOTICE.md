# Distribution notices

This repository is a client distribution channel. It does not contain server installers, server image archives, customer data or operational credentials.

Software licenses and notices are supplied with the corresponding release. The Android application integrates strongSwan and other components under their recorded licenses. Each Android binary release must identify and make available the matching corresponding source, local modifications, required build scripts and notices. An automatically generated archive of this repository's generic text files is not a substitute for that source package.

A release's checksums identify its files. Installation/update authenticity must also follow the application's package-signature and signed-update policies. Private signing keys are never release assets.
