# Majesti downloads

Official distribution channel for Majesti Android and Windows clients.

Verified downloads will be published in this repository's **Releases**. No client release is available from this repository yet. Use only files from a published release and follow that release's installation instructions.

Releases will include versioned client files, update metadata, checksums and release notes. Android releases will also provide the corresponding source/build material and third-party license notices for that version.

The application still needs the Majesti account service and VPN servers to operate. Hosting downloads here separates application distribution from those services.

For ordinary installation problems, include the application version, operating system and a redacted error code in an issue. Do not post passwords, sign-in tokens, private activation/configuration files, recovery codes, personal account information or raw connection logs. Use a private reporting channel for sensitive issues; a public issue is not appropriate for confidential information.
